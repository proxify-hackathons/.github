# proxify-hackathons/.github

Public profile page of the `proxify-hackathons` GitHub org (where hackathon submissions live).
GitHub shows `profile/README.md` on https://github.com/proxify-hackathons.

- `profile/banner-light.svg` / `banner-dark.svg`: the header block. Generated: edit and run
  `python3 scripts/make_banner.py`, never hand-edit the SVGs. Colours are the Proxify brand
  file's Soft (light) and Hero (dark) combinations.
- `profile/avatar.png`: the org avatar (Proxify mark, dark on white, 1000×1000). GitHub has no
  API for org avatars: an org owner uploads it in Settings → Profile.
- Page copy is Julia's to approve. Don't add prose to the README without her text.
